# LEYENDA DE CAMPOS

| Campo | Descripción / Valores |
|-------|-----------------------|
| Ítem | Número correlativo de la actividad |
| Pozo | Identificador del pozo (ej: EA11619D, AA18009) |
| Batería | Código de batería (ej: ZA02, CA-16) |
| Producción (bopd) | Producción del pozo en barriles por día |
| Requerimiento | Descripción del trabajo solicitado |
| Estado | 0 = Pendiente \| 1 = Completado \| Decimal = Parcial (ej: 0.3, 0.8) |
| Tipo | MC = Mant. Correctivo \| MP = Mant. Preventivo \| OEFA = Emergencia ambiental \| SUS = Suspendido |
| Relevante | 1 = Si \| 2 = No |
| Cuadrilla | Guardia \| Adicional |
| Actividad Ejecutada | Descripción detallada del trabajo realizado |

## Evidencias (IMÁGENES / SEGURIDAD Y MEDIO AMBIENTE)

| Campo | Descripción / Valores |
|-------|-----------------------|
| N Evidencia | Número correlativo de la evidencia fotográfica |
| Ítem Ref. | Número de ítem al que corresponde la imagen |
| Pozo / Equipo | Equipo o pozo donde se tomó la foto |
| Descripción | Contexto |
| Hallazgos | Lo que se encontró al inspeccionar |
| Acción Tomada | Lo que se hizo |
| Responsable | Persona o cuadrilla que ejecutó la acción |
| Fecha / Hora | Cuándo se tomó la evidencia |
| Imagen | Insertar foto directamente en la celda |
